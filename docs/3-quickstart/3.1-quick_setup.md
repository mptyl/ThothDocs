# Quick Setup
Con il Quick Setup ti consente di provare subito ThothAI con il database di esempio California Schools.

## 1. Esecuzione sotto Docker (consigliata)

- **Login immediato**: è già presente l'utente `demo` con password `demo1234` associato al workspace `demo`.
- **Workspace demo**: il workspace `demo` utilizza il database `california_schools` collegato alla collection `california_schools`.
- **Accesso**:

    - Backend (Django): `http://localhost:8040`
    - Frontend (ThothUI): `http://localhost:3040`

**Prova subito**: accedi al frontend con `demo/demo1234` e formula domande in linguaggio naturale sul database `california_schools`.

### 1.1 Esempi pronti (data/dev.json)

- Alla root del progetto, nella directory `data/`, trovi il file `dev.json`.
- Contiene ~90 esempi tra domande, hint e SQL di riferimento per il database `california_schools`.
- Questi contenuti sono usati dal setup demo per preprocessing e few-shots.

## 2. Esecuzione in locale (setup equivalente al demo Docker)

Per replicare in locale il seed automatico del demo Docker:

### 2.1 Migrazioni Django

```bash
cd backend
# Carica le variabili da .env.local in modo semplice (macOS/Linux)
set -a; source ../.env.local; set +a
# Evita conflitti con una variabile PORT generica
unset PORT

uv run python manage.py migrate
```

#### Su Windows (PowerShell)

```bash
cd backend
Get-Content ..\.env.local | ForEach-Object {
  if ($_ -match '^\s*([^#]\w+)=(.*)') {
    [System.Environment]::SetEnvironmentVariable($matches[1], $matches[2], "Process")
  }
}
$env:PORT = $null
uv run python manage.py migrate
```

### 2.2 Caricamento setup di default (seed)

```bash
cd backend
# Carica le variabili da .env.local in modo semplice (macOS/Linux)
set -a; source ../.env.local; set +a
# Evita conflitti con una variabile PORT generica
unset PORT

uv run python manage.py load_defaults --source=local
```

#### Su Windows (PowerShell)
```bash
cd backend
Get-Content ..\.env.local | ForEach-Object {
  if ($_ -match '^\s*([^#]\w+)=(.*)') {
    [System.Environment]::SetEnvironmentVariable($matches[1], $matches[2], "Process")
  }
}
$env:PORT = $null
uv run python manage.py load_defaults --source=local
```

Effetti:

- Crea gruppi/utenti di esempio (incluso `demo` con workspace `demo`).
- Configura AI models, agenti, database `california_schools` e workspace.
- Popola il vector DB utilizzando `data/dev.json` (~90 esempi).

In caso di conflitti (es. errori "UNIQUE constraint failed"), puoi pulire le strutture esistenti prima di riprovare:

```bash
# Su Unix/macOS (bash/zsh)
# Pulizia base (struttura DB e workspace)
uv run python manage.py load_defaults --source=local \
  --clean-db-structure --clean-workspaces

# Pulizia completa (ATTENZIONE: cancella anche utenti e gruppi)
uv run python manage.py load_defaults --source=local --clean-all
```

#### Pulizia base (struttura DB e workspace)
```bash
uv run python manage.py load_defaults --source=local 
  --clean-db-structure --clean-workspaces
```

#### Pulizia completa (ATTENZIONE: cancella anche utenti e gruppi)

